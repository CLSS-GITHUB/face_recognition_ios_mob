## 6.3 Pinning & version policy

- **`tflite_flutter`** is the most version-sensitive plugin. Lock to a tested patch (e.g., `0.11.0`) until end-to-end tests pass; auto-bumps have historically broken delegate config on Android 14+.
- **`camera`** is also sensitive; `0.11+` is required for Android 15 / API 35 compatibility.
- **`google_mlkit_face_detection`** ships ML Kit native binaries; expect ~10–15 MB APK size impact, similar to the Android baseline.
- **`drift`** is stable; stick to `^2.20`.

## 6.4 What gets bigger / smaller

Approximate APK size deltas vs. the current Android build:

| Component | Android baseline | Flutter port | Δ |
|---|---|---|---|
| Compose runtime | ~3 MB | n/a | -3 MB |
| Flutter engine | n/a | ~7–10 MB (split-per-ABI) | +7–10 MB |
| ML Kit face detection | ~12 MB | ~12 MB | ≈0 |
| TFLite + GPU delegate | ~3 MB | ~3 MB | ≈0 |
| MediaPipe Tasks Vision | ~9 MB | 0 (dropped) | -9 MB |
| MobileFaceNet model | ~5 MB | ~5 MB | ≈0 |

Net: roughly equivalent on Android; on iOS the Flutter engine adds weight that has no Compose counterpart in the source comparison.

## 6.5 Dropped libraries (final list)

Drop these — they are unused in the live Kotlin source path. Resurrecting any of them should require re-justification.

- `mediapipe-tasks-vision`, `mediapipe-face-landmarker`, `mediapipe-face-detection`
- `retrofit`, `converter-moshi`, `okhttp`, `logging-interceptor`, `moshi-kotlin`, `moshi-kotlin-codegen`, `gson`
- `androidx-datastore-preferences`
- `play-services-location`
- `yoonit-facefy`
- `accompanist-permissions` (replaced by `permission_handler`)
- `coil-compose` (replaced by `Image.file`)
